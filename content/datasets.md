# Datasets

Dataset choice determines which claims a method can support. Detection-oriented datasets emphasize temporal or spatial localization; category-oriented datasets add anomaly classes; anomaly-understanding resources add captions, question answering, grounding, or explanations.

## Annotation dimensions

Temporal annotation may be video-, frame-, or segment-level. Spatial annotation can include boxes, tracks, or pixel masks. Semantic annotation ranges from category labels to free-form explanations.

## Evaluation cautions

Dataset names alone do not establish comparability. Reports should state the split, preprocessing, supervision, test-time information, and metric implementation. See the structured Datasets and Benchmarks pages for sample metadata.
